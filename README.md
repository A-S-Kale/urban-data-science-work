## Data Science Practical Applications kind of finished

In this assignment I completed tasks in Python involving uploading, cleaning, transforming and analysing data to investigate relationships between different types of land and the air pollutant recordings noted at these locations. 

Datasets that were used were:
* DEFRA Modelled Background Pollution Data (mean annual levels of Nitrogen Oxide, Nitrogen Dioxide and Sulfur Dioxide in England)
* Dominant land cover category across England derived from the UK Centre for Ecology and Hydrology Land Cover Map series.
* Eurostat Local Administrative Unit geographical boundaries (LAU2) 

I successfully used matplotlib, seaborn. pandas, numpy, sklearn, pysal, geopandas and contextily packages to clean, visualise and spatially analyse these data. Data analysis techniques I used included geographically weighted regression, local indicators of spatial autocorrelation, global and local Moran's I, OLS multiple regression, decision tree classification and k means clustering. 

Visualisation techniques I used to do this included clustered boxplots, correlation heatmaps, categorised scatter plots, elbow plots, confusion matrices, choropleths and Moran scatterplots.
